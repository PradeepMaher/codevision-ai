# CodeVision AI 🤖💻

**CodeVision AI** is an AI-powered coding assistant built to help developers understand, analyze, debug, and improve their code.

The project combines a modern web interface with generative AI to provide intelligent assistance for programming-related tasks.

AI-powered coding assistant for understanding, analyzing, debugging, and improving code.

🚀 **Live Demo:** https://codevision-ai-ten.vercel.app/generate

## 🚀 Features

* 🤖 AI-powered coding assistance
* 🔍 Code analysis and understanding
* 🐛 Debugging assistance
* 💡 Code explanations
* ✨ Code improvement suggestions
* 💬 Interactive AI conversation
* ⚡ Modern and responsive web interface

## ⚙️ Getting Started

First, clone the repository:

```bash
git clone https://github.com/PradeepMaher/codevision-ai.git
```

Navigate to the project directory:

```bash
cd codevision-ai
```

Install the dependencies:

```bash
npm install
```

Create a `.env.local` file and add your required environment variables.

Example:

```env
GEMINI_API_KEY=your_api_key
```

**Never commit your API keys or secrets to GitHub.**

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

The application will automatically update as you modify the source code.
